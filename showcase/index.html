TERMINAL WORKFLOW

Commands Behind the Lab

Practice inspecting resources and managing labels.

~/kubernetes-day6
# Inspect the active context
kubectl config view --minify

# List Pods and labels
kubectl get pods --show-labels

# Filter by a label
kubectl get pods -l app=web

# Add a custom label
kubectl label pod POD_NAME owner=azeem

# Remove a custom label
kubectl label pod POD_NAME owner-

# Inspect both environments
kubectl get pods -n dev
kubectl get pods -n prod
